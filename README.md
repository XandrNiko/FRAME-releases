# FRAME — личный кинотеатр

Готовые Windows-сборки и канал автоматических обновлений FRAME.

**[Скачать последнюю версию](https://github.com/XandrNiko/FRAME-releases/releases/latest)**

1. Скачайте файл `FRAME-<версия>-Setup.exe` со страницы релиза.
2. Запустите установщик и откройте FRAME через ярлык.
3. Следующие обновления приложение найдёт и загрузит само. Они устанавливаются при выходе или по кнопке перезапуска в карточке обновления.

При переходе с версии 4.0 установите 4.1 один раз вручную: в старой версии ещё нет автообновлений. Библиотека хранится отдельно от приложения и сохраняется при обновлении.

ZIP подходит для запуска без установки. Для автоматической установки обновлений используйте Setup.

Исходники находятся в закрытом репозитории. В этом репозитории публикуются только готовые сборки, описание изменений и файлы канала обновлений. Пользовательские библиотеки, заметки и ключи в него не попадают.
